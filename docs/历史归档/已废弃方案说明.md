# 已废弃方案说明

本文记录不再作为当前 Router 主线使用的历史方案，避免旧概念重新进入新实现。

## Passport assertion

Router 当前身份登录不再使用 Passport assertion。

当前模型：

1. 钱包插件登录使用钱包身份 presentation。
2. 无钱包插件登录使用 Node 钱包身份授权码流程。
3. Router 以钱包身份 DID 作为外部身份主键。

## Passport subject

旧 `subjectId` / `sub_xxx` 不再作为新身份协议的用户主键。若代码中仍存在业务对象 `subjectId`，需要区分它是否只是内部业务对象标识，不应把它恢复为 Passport 身份主键。

## Router 侧通行证注册

通行证注册、查看和撤销已收口到 Wallet 和 Node 身份服务。Router 不提供通行证注册入口。
