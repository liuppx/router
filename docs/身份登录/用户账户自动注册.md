# 用户账户自动注册

Router 本地用户承载管理后台权限、状态、套餐、余额和 API Token。钱包身份 DID 是外部身份主键，Router 用户是本地业务账户。

## 身份字段

- `did`：钱包身份 DID，优先作为外部身份关联字段。
- `walletAddress`：钱包身份关联链账户，用于展示和链上场景，不作为主键。
- `email`：Router 当前要求的已验证邮箱。
- `username`：可选用户名凭证。
- `avatar_url`：可选头像凭证。

## 自动注册

首次钱包身份登录时，如果 Router 没有找到已关联 DID 的用户，可以根据登录结果自动创建本地用户。

自动注册必须满足：

1. 登录结果包含合法钱包身份 DID。
2. 登录结果包含已验证邮箱。
3. 钱包地址通过身份凭证或 presentation 校验。
4. 用户未被禁用。

## 更新策略

每次登录时，Router 可以从身份凭证同步：

1. 钱包身份 DID。
2. 钱包地址。
3. 邮箱。
4. 用户名。
5. 头像地址。

头像是可选资料。缺少头像凭证不应阻塞登录。

## 主键原则

Router 新身份链路以 DID 为主。钱包地址只作为 DID 关联账户保存，避免用户更换地址、增加地址或切换链账户时破坏 Router 用户关系。
