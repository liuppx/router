# 官方模型目录核验记录

核验日期：2026-10-25，时区：Asia/Shanghai。

本次核验基于供应商官方模型目录、价格页和生命周期页。变更由 migration `202610251200_refresh_official_provider_catalog` 写入，范围仅为供应商模型目录及其基础价格/价格组件：

- 不自动创建或启用 `channel_models`；
- 不自动启用渠道端点或发布分组模型；
- 不覆盖渠道层人工价格；
- 已弃用或已关闭的模型保留目录记录，用于历史请求、账单和渠道配置识别；
- 公告进入弃用周期的模型标记 `deprecated`，只有截至核验日已经关闭或退休的模型才设置 `is_deleted=true`。

## 暂缓项

Qwen 官方目录已经出现新的音频、实时、Embedding、Rerank 和 Wan 图片模型，但当前 Router 的端点归一与计量元数据不能完整表达其中的独立端点、字符/音频时长计量和多维条件价格。本次继续暂缓，避免把 Embedding/Rerank 错误登记为聊天模型或生成错误默认价。

MiniMax 新文本、视频和语音型号涉及长上下文、促销分层以及分辨率/时长/输入素材组合计费，后续应以独立 pricing-component migration 处理，不在本次基础目录刷新中压平。

OpenAI 价格页中的 `gpt-5.5-cyber` 及仅面向获批研究组织的 Rosalind 型号没有作为普通可路由目录项加入；受限可用不等于平台默认渠道可用。

## 实现与兼容性

新增 `provider_catalog_refresh_20261025.json` 作为增量目录，不再复制整份历史快照。加载器现在按供应商 ID 合并多个目录文件，再按 canonical model name 合并模型：

- 首次出现决定供应商顺序；
- 后续非空供应商元数据覆盖旧值；
- 后续同名模型执行完整替换，要求增量文件提供完整记录；
- 新模型追加到供应商完整目录，migration 刷新时不会误删历史快照里的其他模型；
- 显式基础类型标签优先于名称推断，避免 `gpt-live-1` 这类名称被误判为文本模型。
