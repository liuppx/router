# 模块边界

本文定义 Router 与 Wallet、Node、web3-bs 的职责边界。

## Router 负责

1. 管理后台登录会话。
2. 钱包身份登录结果校验和本地用户映射。
3. 用户自动注册、启用、禁用和角色判断。
4. API Token 管理。
5. 分组、供应商、渠道、模型和端点配置。
6. 模型请求鉴权、路由、转发、重试和日志。
7. 套餐、余额、计费、扣费、支付和财务分析。
8. Router 自身部署、配置、运维和排障。

## Router 不负责

1. 创建钱包身份 DID。
2. 生成或维护钱包身份文档。
3. 注册、查看或撤销通行证。
4. 注册、查看或撤销认证器。
5. 签发邮箱、用户名、头像等身份凭证。
6. 维护 Passport assertion 或旧 `subjectId` 身份模型。

## Wallet 负责

1. 创建和保存钱包身份。
2. 管理钱包身份凭证。
3. 管理通行证和认证器入口。
4. 根据用户授权向 Web3 应用出示身份声明。

## Node 负责

1. 作为身份服务签发身份凭证。
2. 作为 WebAuthn RP 支持通行证注册和验证。
3. 提供无钱包插件场景的钱包身份授权码登录。
4. 维护应用中心中的应用标识、回调地址和授权边界。

## web3-bs 负责

1. 为 Router 等 Web3 应用提供可复用的钱包身份登录 SDK。
2. 封装钱包插件登录和通行证登录。
3. 解析 DID、钱包地址、身份凭证和 presentation。
4. 降低各 Web3 应用重复实现身份协议的成本。
