# 配置说明

本文按模块说明 Router 关键配置。具体字段以 `config.yaml.template` 和 `common/config` 为准。

## 基础配置

- `server.public_url`：Router 对外访问地址，用于回调、支付、邮件和跳转链接。
- `database.sql_dsn`：PostgreSQL DSN，当前只支持 PostgreSQL。
- `cache.type`：缓存类型，支持 `local` 或 `redis`。
- `redis.conn_string`：使用 Redis 缓存时必填。

## 认证配置

- `auth.cookie_secret`：管理后台 Cookie 签名密钥，生产环境必须替换。
- `auth.jwt_secret`：JWT 和登录态相关密钥，生产环境必须替换。
- `bootstrap.root_wallet_address`：可选，用于初始化系统级管理钱包地址。

## 钱包身份配置

- `identity.node_url`：Node 身份服务地址，仅用于无钱包插件的通行证登录。
- `identity.app_id`：Node 应用中心里的 Router 应用标识，仅用于无钱包插件的通行证登录。
- `identity.callback_url`：可选，Router 身份回调地址；为空时根据 `server.public_url` 生成。

钱包插件登录由 Router 本地校验钱包身份 presentation，不依赖 `identity.app_id`。

## 路由和计费配置
