# 核心概念

本文统一 Router 文档中的核心术语，避免把身份、账户、渠道、模型和计费概念混用。

## 身份与用户

钱包身份 DID：

Router 识别 Web3 用户身份的外部主键，格式为 `did:yeying:wid_*`。Router 用户应优先关联 DID，而不是把钱包地址作为长期身份主键。

钱包地址：

钱包身份关联的链账户属性，可用于展示、链上操作或历史登录衔接。钱包地址不是 Router 的身份主键。

通行证：

用于无钱包插件场景的钱包身份认证方式。通行证不是独立身份主体，最终仍回到钱包身份 DID。

认证器：

钱包身份下的登录因子，例如 Passkey 或后续 TOTP。认证器由 Wallet 和 Node 身份服务管理，Router 只消费登录结果。

Router 用户：

Router 本地账户，承载角色、状态、额度、套餐、API Token 和管理后台权限。Router 用户可以关联钱包身份 DID、钱包地址、邮箱、用户名和头像。

## 路由与模型

供应商：

提供模型服务的上游主体，例如 OpenAI、Anthropic、阿里云、火山等。

渠道：

Router 中可调用的具体上游配置，包含供应商、密钥、端点、状态、权重、模型映射和账务配置。

模型：

用户请求的模型名称，也是路由、计费和能力展示的关键维度。

端点协议：

请求和响应遵循的协议形态，例如 Chat Completions、Responses、Messages、Embeddings、Images。

分组：

Router 暴露给用户的模型和渠道集合边界，用于隔离可见模型、路由范围和权益策略。

## 计费与权益

套餐：

用户购买或分配的权益包，定义周期、额度、并发、次数和兜底策略。

余额：

用户可用于按量扣费的账户资产。

扣费：

Router 在请求前后对套餐、余额和日志进行的结算行为。

采购成本：

Router 调用上游渠道产生的成本，用于毛利和经营分析。
