# 用户权限说明

本文描述 Router 本地用户权限边界。

## 用户类型

管理员：

可以访问管理后台的系统配置、用户、渠道、模型、财务和运营能力。

普通用户：

可以使用分配给自己的模型能力、套餐、余额和 API Token。

## 身份与权限边界

钱包身份 DID 只证明用户是谁，不直接代表 Router 权限。Router 权限由本地用户记录、角色、状态、分组、套餐和 Token 决定。

## 禁用用户

禁用用户后：

1. 不应允许登录管理后台。
2. 不应允许继续使用 API Token。
3. 历史日志、计费记录和支付记录应保留。

## 自动注册默认权限

自动注册用户应使用最小默认权限。具体默认分组、默认套餐和额度策略由运营配置决定。
